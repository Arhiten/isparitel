# Формы для шликерного литья

Фото + габариты → файлы для 3D-печати оснастки:

```
изделие (+) → гипсовая форма (−) → силиконовый кейс (+) → печатный блок + кожух (−)
```

Готов **модуль 1** (фото профиля → STL мастер-модели с учётом усадок), план гипсовой формы (модуль 2),
проверка стола принтера (модуль 4) и расчёт материалов (модуль 5). Статус и порядок работ — `docs/ROADMAP.md`.

## Запуск (Windows, PowerShell)

```powershell
npm install
npm run dev        # http://localhost:3030
npm test           # проверка ядра: модуль 1 (пишет out/test-vase.stl) + план формы, стол, материалы
```

Пример фото для проверки: `samples/vase.jpg` (высота 160 мм, макс. Ø 110 мм).

## Как работает модуль 1

1. **Силуэт.** Если у PNG прозрачный фон — маска по альфе. Иначе яркость, порог Оцу; что темнее —
   фон или изделие — определяется по краям кадра. Остаётся крупнейшая связная область, «дыры» внутри
   (блики, рисунок) заливаются.
2. **Профиль.** Для каждой строки — левая и правая граница. Ось — медиана центров по средним 80% высоты.
   Радиус — половина ширины строки (или одна сторона, если другая испорчена тенью).
3. **Масштаб.** Высота задаёт вертикальный масштаб. Если задан макс. диаметр — радиальный масштаб
   считается по нему; расхождение > 3% выдаёт предупреждение о перспективе.
4. **Усадки.** `модель = готовое / (1 − усадка_глины)`, плюс поправки на гипс и силикон.
5. **Тело вращения.** Число сегментов подбирается так, чтобы хорда отклонялась от окружности ≤ 0,05 мм.
   Плоское дно и плоский верх на уровне края. Сетка проверяется на замкнутость и правильные нормали.

### Ограничения

- Только тела вращения (вазы, чашки, пиалы, бутылки). Ручки, носики, овальные формы — позже.
- Фото с перспективой занижает диаметр широкой части относительно ближних к камере зон: снимайте
  издалека с зумом и задавайте макс. диаметр.
- Плоский верх означает сплошную модель. Полость внутри изделия при шликерном литье образуется сама.
