## 2. Гипсовая форма — `src/core/mold/`

| Файл | Что | Статус |
|---|---|---|
| `types.ts` | параметры формы, план, части | ✔ |
| `spare.ts` | засор: ступенька + воронка над краем | ✔ |
| `undercuts.ts` | поднутрения при съёме вверх, участки без уклона, горло | ✔ |
| `plan.ts` | выбор схемы (цельная / две боковины + дно), габарит блока, замки, пазы, предупреждения | ✔ |
| `build.ts` | тела частей: блок − полость, разрез, замки male/female, пазы (только на гранях ±Y); фаски ☐ | ✔ |

Решения, принятые в каркасе:
- Блок по умолчанию **прямоугольный**: у каждой части плоская тыльная грань — на неё
  заливается гипс в силиконовый кейс (модуль 3).
- Разъём боковин — плоскость `x = 0` через ось; дно отделяется плоскостью `z = 0` (по низу изделия,
  шов легко зачистить).
- Замки: на плоскости боковин по 2 с каждой стороны полости (внизу и вверху), на плоскости дна —
  4 по углам. Выступ — на боковине A и на дне, гнездо — в ответной части с зазором ~0,3 мм.
- Проверка: `отступ замка от полости + диаметр + 4 ≤ толщина стенки`, иначе предупреждение.

**Готово, когда:** для вазы получаются 3 тела, суммарный объём гипса = блок − полость (±0,5%),
замки совпадают по центрам; для пиалы — 1 тело.

## 3. Кейс и кожух — `src/core/case/`

| Файл | Что | Статус |
|---|---|---|
| `types.ts` | параметры кейса/кожуха, печатные детали, объём силикона | ✔ |
| `estimate.ts` | оценка без CSG: гипс по частям, силикон, габариты блока/основания/стенок | ✔ |
| `build.ts` | укладка части, блок со штифтами, основание, стенки с ушками и болтами, риска уровня; паз уплотнения и буртик ☐ | ✔ |

Метод: печатный **блок** (копия части гипсовой формы) кладётся тыльной гранью на основание,
вокруг — стенки с зазором = толщина силикона, **открытая заливка** силикона сверху.
Потом кейс переворачивается, ставится обратно в кожух (жёсткая рубашка), заливается гипс.

**Готово, когда:** для каждой части формы получаются блок + основание + 2 или 4 стенки,
все детали замкнуты, объём силикона = внутренний объём кожуха − блок.

## 5. Материалы — `src/core/materials/`  ✔

Гипс (масса порошка и воды по консистенции), силикон (A/B по массе с запасом), шликер
(сколько залить, сколько останется в стенке), стоимость по ценам за кг.

Проверено: 1 л формы при консистенции 70 → 922 г гипса + 645 г воды (сходится с таблицами
производителей гипса, ~0,92 г/см³).
